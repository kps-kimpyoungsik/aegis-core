# Portable Brain Skill Tree

All managed skill information must follow `docs/governance/INFORMATION_TREE_STANDARD.md`.

Canonical shape:

`{field}/{area}/{relation}/{module}/{unit}`

where `unit` starts with `service-`, `resource-`, or `page-`.

Root-level files are governance/index metadata only. Do not place executable/procedural skills directly under this root. New information must be classified, deduplicated, owner-resolved, and routed before creation. More than five semantic folder levels must be compressed into L5 metadata/files or split into sibling L5 units.
