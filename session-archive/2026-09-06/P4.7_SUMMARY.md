# AEGIS P4.7 — Pluggable Multimodal Asset Ingestion & Extraction Fabric

Status: `P4_7_SIMULATION_PASS`

Implemented a technology-independent plugin boundary for turning large heterogeneous sources into reusable searchable assets. The design deliberately does **not** create one giant multimodal engine. Each extractor is independently attachable/detachable and owns only its modality capability.

Reference implementation included:
- AssetEnvelope with source identity/hash/provenance anchor.
- ExtractorPlugin contract + PluginRegistry attach/detach.
- ExtractionRouter for explicit requested capabilities.
- Typed Signal outputs.
- Deterministic text chunker reference plugin.
- Projection freshness guard.
- Capability catalog covering image, speech, sound-event, video frame, expression signals, future taste/touch/context sensors, and multimodal fusion as separate modules.
- Impact matrix defining what each module affects and does not affect.

Not implemented/promoted:
- image model
- OCR/vision model
- speech model
- sound classification model
- face/expression model
- taste/touch hardware
- multimodal fusion model

Those remain `CONTRACT_ONLY` / `FUTURE_CONTRACT_SLOT` until real evidence and runtime tests exist.

Safety/meaning boundary: expression-related outputs are signals only and cannot be treated as authoritative identity, intent or mental state. Derived signals remain rebuildable projections and never replace the source asset.
