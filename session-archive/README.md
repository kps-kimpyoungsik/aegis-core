# Session Convergence Archive

This branch preserves the AEGIS R0.5 executable product tree under `product/` and records the current-session file inventory separately. Historical session files that are not physically present in the current runtime are not claimed as uploaded.

Canonical implementation basis for subsequent work: `product/`.

The current runtime inventory contained 102 AEGIS files (2,189,876 bytes) across current product sources, constitutional/source documents, and release snapshots. Generated `node_modules` workspace links are excluded and must be recreated by bootstrap/install.
