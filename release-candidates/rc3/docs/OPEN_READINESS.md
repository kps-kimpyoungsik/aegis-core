# AEGIS-CLI Customer Launch Readiness

## Current decision

**NO-GO for public customer launch.**

This is a release-gate decision, not an architecture rejection. The architecture and Java runtime baseline are progressing, but production evidence is incomplete.

## Verified now

- Java 21 compile with warnings as errors
- architecture dependency guard
- runtime kernel tests
- execution fence stale-token rejection
- tenant isolation smoke
- static PostgreSQL migration contract
- server liveness/readiness behavior
- fail-closed readiness when PostgreSQL is required but unavailable
- JAR packaging and SHA256 manifest

## Release blockers

1. Real PostgreSQL migration/CRUD/outbox/inbox/restart/concurrency E2E is not executed.
2. Backup and restore drill is not executed.
3. React SPA production build is not verified; `package-lock.json` is absent and `package.json` contains floating `latest` dependencies.
4. OCI image build/scan is not executed in the current environment.
5. Kubernetes deployment is only manifest-level; staging apply/rollout/smoke/rollback is not executed.
6. H2 security release corpus is designed but not physically executed as a release gate.
7. SBOM and SLSA-style build provenance/attestation are not yet generated by the current pipeline.
8. Authentication/authorization for public customer use is not evidenced in the current RC.
9. TLS/ingress/rate-limiting/production secret integration is not evidenced.
10. Operational SLO/alert thresholds and on-call/runbook acceptance are not measured.

## Go criteria

Public launch requires all blockers closed with immutable evidence. A marker file is intentionally required by `scripts/release-readiness.sh` only after the corresponding real test is executed and its report is committed/attached to the release evidence bundle.

## Deployment baseline candidate

- Java 21 runtime.
- PostgreSQL 18.x or 17.x on a currently supported minor; use the latest minor of the selected major at deployment time.
- Kubernetes 1.36.x as the conservative initial production baseline unless 1.37.x is explicitly qualified by staging regression; do not hard-code this into the Core.
- OCI images referenced by digest, not mutable tags.
- React SPA built from a committed dependency lock.
